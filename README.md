# Node.js + MySQL Backend (Initial Setup)

This is a basic backend project built using **Node.js**, **Express**, and **MySQL**.  
The project is in its **initial stage** and focuses only on setting up the server and database connection.

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MySQL
- mysql2
- dotenv
- nodemon

---

## 📁 Project Structure

```
project-root/
│
├── app.js # Main server file
├── config/
│ └── db.js # MySQL connection
├── .env
├── package.json
└── README.md
```
